# AGENTS.md

## Cursor Cloud specific instructions

### Project overview

This is an STM32F103RCT6 embedded firmware project (Environmental Monitoring Station). It produces ARM Cortex-M3 firmware binaries — it cannot be "run" on the VM, only compiled.

### Build system

PlatformIO is the primary build system. The ARM cross-compiler toolchain (`arm-none-eabi-gcc`) is auto-installed by PlatformIO on first build.

- **Build**: `pio run`
- **Clean**: `pio run -t clean`
- **Output**: `.pio/build/genericSTM32F103RC/Ems_<version>.elf`, `.hex`, `.bin`

### Linux case-sensitivity fixes

The project was developed on a case-insensitive filesystem (macOS/Windows). Two fixes were applied for Linux:

1. `platformio.ini`: Added `-I` paths for each `Lib/` subdirectory and `-D LV_LVGL_H_INCLUDE_SIMPLE` — PlatformIO auto-discovers `Lib/` as `lib/` on case-insensitive systems but not on Linux.
2. `Lib/crc8/crc8.h`: Changed `#include "Stddef.h"` to `#include "stddef.h"` (standard C header is lowercase).

### Notes

- There are no automated tests in this codebase.
- There is no linter configured; compiler warnings serve as the primary code quality check.
- The `Makefile` in the project root is auto-generated by STM32CubeMX and only covers Core/Drivers (not the full project). Use `pio run` instead.
- `pio` must be on `PATH` — it is installed to `~/.local/bin` via `pip3 install platformio`.
