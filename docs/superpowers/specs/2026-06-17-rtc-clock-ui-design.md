# RTC 时钟界面设计

日期：2026-06-17
项目：RT-103，STM32F103RCT6 环境监测站固件

## 目标

新增一个真实 RTC 时钟作为默认 UI 主界面。设备开机后，OLED 显示由
STM32F103 RTC 和 32.768 kHz LSE 晶振提供的 `HH:MM:SS` 时间。双击按键进入
现有菜单列表，这个列表作为二级菜单使用。二级菜单保留当前已有条目，并新增
`Time Set` 和 `RTC Calib`。

## 当前上下文

UI 主要集中在 `App/display.c`。

- `ui_task()` 负责初始化 U8G2 并运行显示循环。
- `gesture_task()` 负责投递单击、双击、长按事件。
- 当前菜单行为是单击移动选中项，长按执行选中项。
- 当前已有的独立显示页面使用双击作为退出手势。
- `RT.ioc` 已经把 PC14/PC15 配成 LSE，并选择
  `RCC_RTCCLKSOURCE_LSE`，但还没有把 RTC 作为 `.ioc` 外设启用，也没有
  `MX_RTC_Init()` 代码路径。

## 用户可见行为

### 时钟主界面

在启动和 storage/UI 初始化完成后，默认进入时钟主界面。界面显示当前 RTC
时间，格式为 `HH:MM:SS`。

如果 RTC 尚未设置，时钟界面不能显示一个看起来有效但实际不可信的时间。它应
显示未设置状态，例如 `--:--:--`，同时仍然允许进入菜单。

时钟主界面按键行为：

- 单击：第一版不执行动作。
- 双击：进入二级菜单。
- 长按：第一版不执行动作。

### 二级菜单

二级菜单复用现有列表 UI 和选择行为。

二级菜单按键行为：

- 单击：移动选中项。
- 长按：执行选中菜单项。
- 双击：返回时钟主界面。

菜单保留当前已有注册项，并追加：

- `Time Set`
- `RTC Calib`

### Time Set

`Time Set` 提供一个最小可用的单按键时间编辑器，用于编辑小时、分钟、秒。

按键行为：

- 单击：递增当前字段。
- 长按：切换到下一个字段。
- 双击：保存编辑后的时间到 RTC，并返回菜单。

第一版只编辑当天时间，不包含日期编辑。

### RTC Calib

`RTC Calib` 用于编辑软件校准值，单位是每天补偿秒数。示例：

- `+2 s/day`：显示时间每天向前补偿 2 秒。
- `-2 s/day`：显示时间每天向后补偿 2 秒。

这个方案不依赖 STM32F1 的硬件校准寄存器，UI 和校准逻辑都更容易理解。

按键行为：

- 单击：递增校准值。
- 长按：切换方向或切换编辑状态。
- 双击：保存并返回菜单。

校准值持久化到现有 EEPROM 配置区域。该配置区域会在保持旧版行为可用的前提
下扩展，以便处理旧 EEPROM 数据。

## RTC 与 CubeMX 配置

需要同步更新 `.ioc` 文件，使 STM32CubeMX 打开 `RT.ioc` 时能够看到 RTC 已
配置。

`.ioc` 需要表达的配置意图：

- 保持 PC14/PC15 为 LSE 外部晶振。
- 保持 `RCC.RTCClockSelection=RCC_RTCCLKSOURCE_LSE`。
- 把 RTC 加入已启用的 MCU IP 列表。
- 添加 STM32F1/CubeMX 期望的 RTC 虚拟引脚或功能项。
- 把 `MX_RTC_Init` 加入项目初始化函数列表。

代码侧 RTC 支持需要初始化备份域，并配置 RTC 使用 LSE 产生 1 Hz 计数。
STM32F1 的 RTC 保存的是秒计数器，因此固件需要把秒计数转换成 `HH:MM:SS`
用于显示。

## 架构

### RTC 模块

新增一个聚焦的 RTC 模块，用于硬件访问和软件校准计算。

职责：

- 初始化 RTC、LSE 和备份域，并避免破坏已经配置好的 RTC。
- 判断 RTC 是否已有有效的设置时间标记。
- 读取和写入 RTC 原始秒计数器。
- 把原始秒计数加上软件校准后转换为 `HH:MM:SS`。
- 通过 storage API 保存和读取校准相关配置。

### Storage

扩展持久化配置，加入时钟 UI 所需数据：

- 上次选中的二级菜单项。
- RTC 已设置标记或备份域标记。
- 每天补偿秒数的软件校准值。
- 校准锚点数据，用于避免软件补偿不断累积舍入误差。

storage 变更需要在发现旧 EEPROM 内容时保持现有行为，并回退到默认值。

### Display

`App/display.c` 增加一个简单的顶层 UI 模式：

- 时钟主界面模式。
- 二级菜单模式。
- 弹出动作/编辑器模式。

当前菜单列表渲染器继续作为二级菜单渲染器使用。新增时钟渲染器与它并列，而
不是替换现有菜单渲染逻辑。

### Menu Registry

`App/ui_menu_registry.c` 继续注册现有菜单项，同时注册 `Time Set` 和
`RTC Calib` 动作。

## 动画

动画必须足够轻量，适合 STM32F103 和 U8G2 全缓冲绘制。

计划优化：

- 继续使用现有插值逻辑处理菜单选择框和滚动。
- 在进入或离开二级菜单时增加轻量的位移过渡。
- 动画进行中快速刷新，静止时降低刷新频率。
- 不引入昂贵特效或额外帧缓冲。

成功标准是让切换观感更顺滑，同时不增加空闲状态下的刷新负载。

## 边界情况

- LSE 启动失败：显示 RTC 不可用或未设置状态，并保持菜单可进入。
- RTC 尚未设置：显示未设置状态，并允许进入 `Time Set`。
- EEPROM 缺失或无效：使用默认值，并保持运行时行为可用。
- 旧版 EEPROM 配置：识别为旧配置后回退默认值。
- 菜单中双击：返回时钟界面，不执行选中动作。
- 关机提示：继续像现在一样优先覆盖普通 UI。

## 验证

这个代码库没有自动化测试，因此以编译和静态行为验证为主。

必需检查：

- `pio run` 编译成功。
- `RT.ioc` 包含已启用的 RTC 外设配置，并保持 LSE 作为 RTC 时钟源。
- 不暂存无关的脏工作区文件。
- 代码路径在时钟显示需要 RTC 之前完成 RTC 初始化。
- 菜单包含现有项目，并新增 `Time Set` 和 `RTC Calib`。
- 通过代码检查和构建输出确认以下路径完整：时钟主界面、双击进入菜单、菜单
  双击返回、时间设置、校准保存。
