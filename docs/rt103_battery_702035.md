| 项目 | 参数 |

| 电芯 / PACK | 702035 / 70T20M35 |
| 额定容量 | 500mAh |
| 标称电压 | 3.7V |
| 充电限制电压 | 4.20V，+0.03V / -0.02V |
| 标准充电电流 | 0.5C = 250mA |
| 最大持续充电电流 | 0.5C = 250mA |
| 标准放电电流 | 0.2C = 100mA |

| 充电温度 | 0C 到 45C |
| 放电温度 | -20C 到 60C |

## 保护板参数

| 项目 | 最小值 | 典型值 | 最大值 |
|---|---:|---:|---:|
| 过充检测 | 4.255V | 4.28V | 4.325V |
| 过放检测 | 2.95V | 3.00V | 3.05V |
| 过流保护 | 1.5A | 2.5A | 4A |
| 自耗电流 | 3uA | - | 7uA |
| 导通内阻 | 50mOhm | - | 60mOhm |

保护板参数只能作为最后的安全保护边界，固件和充电电路不能把保护板动作当作正常充放电控制策略。

## 固件配置

电池参数集中固化在 `App/battery_profile.h`。

关键取值如下：

| 代码配置 | 取值 | 原因 |
|---|---:|---|
| `RT103_BATTERY_FULL_MV` | 4200mV | 规格书满充电压 |
| `RT103_BATTERY_CHARGE_LIMIT_MAX_MV` | 4230mV | 4.20V + 30mV 上公差 |
| `RT103_BATTERY_MAX_CONTINUOUS_CHARGE_MA` | 250mA | 0.5C 最大持续充电 |
| `RT103_BATTERY_MAX_CONTINUOUS_DISCHARGE_MA` | 250mA | 0.5C 最大持续放电 |
| `RT103_BATTERY_UI_EMPTY_MV` | 3300mV | UI 在保护板动作前显示空电量 |
| `RT103_BATTERY_LOW_WARN_MV` | 3400mV | 预留低电量告警阈值 |
| `RT103_BATTERY_SOFT_SHUTDOWN_MV` | 3200mV | 预留软件关机阈值 |
| `RT103_BATTERY_CHART_MIN_MV` | 3000mV | 曲线下限对齐保护板典型过放点 |

ADC 分压和 BATCAL 校准流程保持不变，但校准输入范围已经限制到 `3000mV` 到 `4230mV`，避免按旧配置接受过低或过高的电池电压。

## 硬件和测试注意事项

- 充电电流应配置为不超过 250mA。
- 系统平均工作电流应控制在 250mA 以内。保护板可以承受短时过流，但不能把安培级保护阈值当作产品长期工作电流。
- 软件应在 3.0V 之前告警或准备关机，因为保护板典型过放检测点已经是 3.00V。
- 来料快检可以参考出厂电压 3.75V 到 3.90V、内阻 <= 60mOhm。
- OTA 测试前应保证电池电量充足。当前 A/B OTA 可以提升 Flash 更新掉电恢复能力，但不能避免电池保护板切断导致的整机掉电。
